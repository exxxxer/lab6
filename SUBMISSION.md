# Перед сдачей лабораторной №6

1. Переименовать папку `Фамилия_ИО` в собственную фамилию с инициалами.
2. Установить `uv` и запустить `uv sync` из каталога проекта. Появившийся `uv.lock` добавить в Git отдельным коммитом (в среде подготовки проекта PyPI был недоступен).
3. Скопировать `.env.example` в `.env`. Убедиться, что `.env` находится в `.gitignore`.
4. Проверить `uv run uvicorn main:app --reload`, открыть `/docs`, `/redoc` и выполнить `GET /`, `GET /info`, `GET /items/1`, `POST /items/`, `PUT /items/2`.
5. Выполнить `uv run pytest -q`.
6. Добавить в README.md при необходимости собственные скриншоты браузера Swagger UI (включённые иллюстрации показывают реальные HTTP-ответы, но оформлены для чтения).
7. Указать своё имя и почту в `git config user.name` и `git config user.email` для новых коммитов. Имеющиеся учебные коммиты демонстрируют историю выполнения заданий.
8. Создать на GitHub **публичный** пустой репозиторий, указать его URL вместо примера и отправить проект:

```bash
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/fastapi-lab6.git
git push -u origin main
```

**Не публиковать:** `.env`, `.venv`, `app.log`, токены, пароли.

> Публичная публикация требует учётной записи пользователя. Из локального окружения публикация от чужого имени не выполнялась.
